Hands-on cybersecurity portfolio demonstrating practical experience in enterprise security, SOC operations, network analysis, vulnerability testing, and security administration.

My projects focus on building environments, generating and analyzing security events, troubleshooting systems, and documenting the investigation process rather than only completing isolated exercises.

## Featured Project

### Enterprise Security Homelab

Built a simulated corporate Windows environment in VMware Workstation featuring Active Directory, DNS, Group Policy, pfSense network security, and centralized endpoint monitoring through Wazuh SIEM.

The lab is used to generate and investigate security events, troubleshoot SIEM telemetry pipelines, analyze Windows Event Logs, perform threat hunting, and evaluate alerts using MITRE ATT&CK.

**Technologies:** Windows Server 2025, Active Directory, Group Policy, DNS, Windows 11, pfSense, Wazuh SIEM, Ubuntu Server, PowerShell, Windows Event Logs, MITRE ATT&CK

**SOC Investigation:** Investigated PowerShell Script Block Logging Event ID 4104 and traced telemetry through the complete pipeline from the Windows endpoint through Wazuh collection, detection, indexing, and Threat Hunting.
